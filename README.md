# NG Rules — репозиторий правил

## Структура

```
rules/
  UA/rules.json     ← Україна (активна)
  GE/rules.json     ← Грузія  (заглушка: [] — в программе «Правила в розробці»)
  RO/rules.json     ← Румунія (заглушка: [])
rules.json          ← копия rules/UA/rules.json для СТАРЫХ версий программы (см. ниже)
merge_rules.py      ← скрипт объединения без потерь
```

Программа скачивает **только файл выбранной страны**:
`https://raw.githubusercontent.com/Zozylia/NGrules.json/refs/heads/main/rules/<UA|GE|RO>/rules.json`
Проверка идёт при запуске и при переключении страны (один раз за сессию) + кнопка «Оновити правила».
Нет сети или файла — показывается последняя закэшированная версия, интерфейс не ломается.

## Формат пункта

```json
{ "doc": "Крайм: Постачання", "section": "1. Загальні положення",
  "num": "1.2", "punishment": "Деморган 60 хв", "text": "Текст пункту…" }
```
Все пять полей — строки (пустые допустимы). Файл — JSON-массив `[ {...}, {...} ]`.

## Как программа строит вкладки и подразделы (ничего не прописано в коде)

* Название документа вида **`Категорія: Назва`** → вкладка `Категорія`, подраздел `Назва`.
  Префикс `Держ:` показывается как вкладка «Держструктури».
  Новый префикс (например `Економіка: …`) автоматически станет новой вкладкой.
* Документ **без префикса** (сейчас это «Основні правила проєкту» и «Правила держструктур») → его подразделы = его разделы (`section`).
* Чтобы добавить подраздел: добавьте пункты с новым `doc` (`Крайм: Новий документ`) — кнопка появится сама.

## Новая страна

1. Создайте `rules/XX/rules.json` (можно `[]`).
2. Добавьте код страны в список `COUNTRIES` в `ng_overlay.py` и пересоберите exe (переключатель в шапке — единственное, что в коде заведено вручную).

## Старый `rules.json` в корне

Уже разданные exe берут правила из корня. Пока все не обновились — обновляйте **оба** файла одинаково
(`rules/UA/rules.json` и `rules.json`). Когда exe обновят все, корневой файл можно удалить.

## Частые ошибки

* Сломанный JSON (лишняя/пропущенная запятая) — программа проигнорирует файл и останется на прежней версии. Проверьте файл на https://jsonlint.com до коммита.
* Файл UA с пустым `[]` программа тоже отвергнет (защита от случайного стирания).
